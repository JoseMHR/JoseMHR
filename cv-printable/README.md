# Plantilla de CV Imprimible A4 (1 Sola Cara) 📄

Esta carpeta contiene la maquetación profesional y autónoma del currículum de **José Manuel Heredia Reyes**, diseñada para ajustarse estrictamente a **1 sola página A4** ($210 \times 297\,\text{mm}$) sin desbordamiento ni saltos de página.

---

## 📁 Archivos de esta carpeta:
- **`index.html`**: Plantilla maestra con HTML semántico y CSS A4 calibrado al milímetro.
- **`assets/avatar.jpg`**: Fotografía de perfil circular.
- **`assets/qr-portfolio.png`**: Código QR vectorial que enlaza al CV web interactivo ([https://josemhr.github.io/JoseMHR/](https://josemhr.github.io/JoseMHR/)).
- **`CV_Jose_Manuel_Heredia_Reyes_2026_Draft.pdf`**: El PDF resultante compilado en 1 página exacta.
- **`generate-pdf.bat`**: Script de 1 clic para regenerar el PDF automáticamente utilizando Chrome o Edge en modo headless.

---

## 🚀 Cómo regenerar el PDF:
1. **Opción 1 (Automática por script):**
   Haz doble clic en `generate-pdf.bat`. Compilará instantáneamente `index.html` en `CV_Jose_Manuel_Heredia_Reyes_2026_Draft.pdf`.

2. **Opción 2 (Desde cualquier navegador):**
   Abre `index.html` en Chrome, Edge o Firefox:
   - Pulsa `Ctrl + P`.
   - Destino: *Guardar como PDF*.
   - Tamaño de papel: *A4*.
   - Márgenes: *Ninguno* (el HTML ya incorpora los márgenes internos de 7 mm).
   - Opciones: Marca *Gráficos de fondo*.
   - Haz clic en *Guardar*.
